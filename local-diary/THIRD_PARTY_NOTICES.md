# Memos

The sidebar/card composition and theme tokens in this local diary are adapted from
[usememos/memos](https://github.com/usememos/memos), particularly
`web/src/themes/default.css`, `components/MemoView/constants.ts`,
`components/AppSidebar/`, and the calendar/home page composition.
The reference repository is cloned into the ignored `references/memos` directory.
Reference commit: `1a51572406e1db3e97c24b2497013c8005e88317`.
The local file-backed storage and block editor are implemented in this repository.
