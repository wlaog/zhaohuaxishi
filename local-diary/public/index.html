关于朝花夕拾

所有内容存放在运行服务的电脑上：

新增日记：source/年/月/日/entry-*.json
新增原图：同目录的 media-*.扩展名
历史版本：同目录的 _history/

复制完整数据目录即可迁移。编辑需要 Node.js 和日记服务。请另做独立备份。

可通过 Tailscale 私人网络从其他设备访问同一份日记，电脑需在线且不休眠。没有离线编辑队列；未保存的草稿请勿关闭。日记、图片、身份配置和测试输出均排除在 Git 外，没有第三方统计。
